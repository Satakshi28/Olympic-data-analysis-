# Olympic Data Analysis

## Overview
This project analyzes historical Olympic datasets to extract meaningful insights
and visualize trends related to medal distribution, athlete participation, and
performance over time.

## Dataset
- Source: Public Olympic dataset (Kaggle / open-source)
- Type: Structured CSV data
- Files:
  - athlete_events.csv: athlete-level Olympic event data
  - noc_regions.csv: country and region mappings

## Approach
- Data cleaning and preprocessing
- Feature engineering
- Exploratory data analysis
- Visualization of trends and patterns

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn

```bash
pip install -r requirements.txt
