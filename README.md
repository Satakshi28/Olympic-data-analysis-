# Olympic Data Analysis

This project focuses on analyzing Olympic datasets to find useful insights and patterns.  
It uses Python libraries like **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn** for data cleaning, analysis, and visualization.

## Features
- Medal tally by country
- Performance trends over time
- Gender participation statistics
- Visualizations for better insights

## Tech Stack
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
